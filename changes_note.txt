=================================================================
TROUBLESHOOTING
=================================================================

Error: "DELIM not in msg_list"
→ Wrong Python version. Make sure .venv uses Python 3.13, not 3.14
→ Recreate venv: rm -rf .venv && uv sync --extra policy-mapper

Error: "ModuleNotFoundError: No module named 'ai_atlas_nexus'"
→ Wrong kernel selected or dependencies not installed
→ Select .venv kernel and run: uv sync --extra policy-mapper

Error: "FileNotFoundError" for ai-atlas-nexus
→ Clone the repository:
  git clone https://github.com/IBM/ai-atlas-nexus
  git -C ai-atlas-nexus checkout v1.2.3

Error: ValidationError with "547 validation errors for Container"
→ ai-atlas-nexus version mismatch with Pydantic v2
→ Update both package and data to main branch:
  - Edit pyproject.toml: change v1.2.3 to @main
  - Run: cd ai-atlas-nexus && git checkout main
  - Run: uv sync --extra policy-mapper

Error: Can't connect to vLLM endpoint
→ Check cluster access / VPN connection
→ Verify URL in cell #2 or environment variable

Notebook shows JSON instead of cells
→ Right-click → "Open With..." → "Jupyter Notebook"
→ Install Jupyter extension if needed
